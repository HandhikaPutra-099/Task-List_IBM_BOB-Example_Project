# Task List

A simple and responsive task management application built with HTML, CSS, and JavaScript. Designed to help users organize daily activities, track task progress, and manage their to-do lists through a clean and intuitive interface.

## Overview

**Task List** is a lightweight web application that allows users to manage their daily tasks directly from their browser.

The application provides essential task management features, including adding, editing, completing, filtering, and deleting tasks. Task data is automatically saved using the browser's Local Storage, so users can revisit their tasks without losing their progress when reopening the application in the same browser.

## Features

- **Add Tasks** — Create new tasks with input validation.
- **Edit Tasks** — Update existing task descriptions.
- **Delete Tasks** — Remove individual tasks from the list.
- **Mark as Completed** — Track completed and unfinished tasks.
- **Task Filtering** — Filter tasks by All, Active, and Completed status.
- **Clear Completed** — Remove all completed tasks at once.
- **Task Counter** — Display the total number of tasks and remaining tasks.
- **Local Storage** — Automatically save task data in the browser.
- **Responsive Interface** — Access the application through different screen sizes.

## Getting Started

Follow these steps to run the project locally.

### 2. Navigate to the Project Directory

```bash

```

### 3. Run the Application

## Data Storage

This application uses the browser's **Local Storage** to preserve task data.

All tasks are stored locally in the browser, meaning:

- Tasks remain available after refreshing or reopening the application.
- Data is specific to the browser and device being used.
- No external database or cloud synchronization is implemented.
